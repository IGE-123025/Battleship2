🚀 Installation

``` 
git clone https://github.com/britoeabreu/Battleship2.git

cd Battleship2

mvn clean package

java -jar target/BattleshipGamePlayer-2.0.jar
```

🧪 Testing

``` 
mvn test
```

Unit tests are automatically executed through GitHub Actions on every push and pull request.
